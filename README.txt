PROJECT OMNIVERSE V1

Windows: double-click omniverse.py, or run:
  python omniverse.py

No pip installs required. Uses Python standard library tkinter.
If tkinter is missing, install Python from python.org with Tcl/Tk enabled.

Click planets to select them.
Planet: add a planet (max 7)
Life: start civilization on selected planet
Meteor: reduce selected planet population
Speed: cycle 1x / 10x / 100x
Pause: pause or resume
Save / Load: JSON universe file
Reset: create a fresh universe

This is a 2D simulation, not a realistic physics engine or 3D world.
